# Legacy assets

This directory holds material preserved from the project's earlier
Phaser/Matter.js prototype, kept for reuse now that the project is built on
Fish Folk: Jumpy instead. It is not wired into the current build.

- `physics-arena-texture-pack/` — the custom (AI-generated) texture pack:
  character poses, weapons, projectiles, effects, arena tiles, HUD icons.
  Intended to eventually replace Jumpy's own (CC BY-NC, non-commercial-only)
  sprites once baseline gameplay on the new foundation is confirmed.
- `asset-pipeline.md` — how that texture pack was extracted from its
  original source sheets, in case it needs to be regenerated or extended.
