# Avito monitor → Telegram

Два способа следить за объявлениями Avito и получать новые совпадения в
Telegram:

- **`bot.py`** — полноценный интерактивный Telegram-бот. Управление —
  кнопками (главное меню внизу экрана + inline-кнопки на карточках
  фильтров), без необходимости помнить команды. Добавление фильтра — либо
  через гид по категориям Avito (категория → подкатегория → город →
  опционально ключевое слово/цена), либо вставкой готовой ссылки с сайта.
  Поддерживает много пользователей одновременно, паузу/возобновление,
  свою периодичность на каждый фильтр (кнопками-пресетами), стоп-слова и
  диапазон цены поверх фильтра Avito, переименование и смену ссылки без
  потери истории, уведомления с фото и кнопкой «Открыть на Avito»,
  авто-паузу при долгой блокировке, статистику и админ-рассылку.
  **Это основной, рекомендуемый вариант.**
- **`monitor.py`** — простой скрипт для одного фиксированного чата и
  списка фильтров в `config.json`, задуманный под запуск по cron/GitHub
  Actions. Оставлен для тех, кому не нужен интерактивный бот.

Оба используют общую логику загрузки и парсинга страниц Avito из
`avito_client.py`.

## ⚠️ Важное ограничение

Avito закрывает трафик с дата-центровых IP антиботом Qrator — прямые
запросы из облака (GitHub Actions, большинство VPS/PaaS) могут стабильно
получать `429` и не доходить до реальных данных. Это ограничение
сети/IP, а не кода. Бот не падает молча: после нескольких неудачных
попыток подряд по фильтру он один раз (не чаще раза в 6 часов) пришлёт
предупреждение в чат. Если блокировка постоянная — надёжнее всего гонять
бота там, где IP не в чёрных списках: домашний ПК, домашний сервер,
VPS с «жилым» (residential) IP.

## Быстрый старт (бот)

1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather),
   получите токен.
2. Установите зависимости и запустите:

   ```bash
   cd avito_monitor
   pip install -r requirements.txt
   export TELEGRAM_BOT_TOKEN=123456:ABC-your-token
   python bot.py
   ```

3. Напишите боту `/start` в Telegram, дальше всё через команды —
   `/help` покажет полный список.

### Через Docker

```bash
cd avito_monitor
echo "TELEGRAM_BOT_TOKEN=123456:ABC-your-token" > .env
docker compose up -d --build
```

База (`bot/avito_bot.db`) сохраняется в volume, состояние переживает
перезапуски контейнера.

### Через Railway

⚠️ Railway — облачный (дата-центровый) хостинг, так что применимо то же
предупреждение про антибот Avito, что и выше про GitHub Actions: есть
шанс, что и оттуда запросы будут блокироваться. Бот не упадёт молча —
пришлёт алерт в чат — но будь готов при необходимости переехать на
домашний сервер/VPS с «жилым» IP.

1. New Project → Deploy from GitHub repo → выбери этот репозиторий.
2. В Settings сервиса выстави **Root Directory: `avito_monitor`** —
   `Dockerfile` лежит в этой подпапке, а не в корне репозитория. Railway
   соберёт образ по нему автоматически, дополнительно ничего указывать
   не нужно.
3. Settings → Variables: добавь `TELEGRAM_BOT_TOKEN` (обязательно) и,
   при необходимости, остальные переменные из таблицы ниже.
4. Settings → Volumes: добавь volume и примонтируй на `/app/bot` — там
   лежит SQLite-база с фильтрами, без volume она будет слетать при
   каждом редеплое.
5. Это фоновый воркер (long polling), HTTP-порт не нужен — если Railway
   настаивает на Healthcheck Path, оставь его пустым, чтобы не
   перезапускало контейнер в ожидании HTTP-ответа.
6. После деплоя проверь Logs и напиши боту `/start` в Telegram.

### Как пользоваться ботом

После `/start` внизу экрана появляется постоянное меню:

`➕ Добавить фильтр` · `📋 Мои фильтры` · `📊 Статус` · `📈 Статистика` · `📤 Экспорт` · `❓ Помощь`

**Добавление фильтра** (`➕ Добавить фильтр`) — бот спрашивает, как:

- **🗂 Выбрать категорию** — гид по кнопкам: категория Avito (Недвижимость,
  Транспорт, Электроника, Личные вещи, Для дома и дачи, Хобби и отдых,
  Животные) → подкатегория → город (или «Вся Россия») → опционально
  ключевое слово и диапазон цены → превью с готовой ссылкой и кнопкой
  «🔗 Проверить на Avito» перед сохранением.

  ⚠️ **Честно предупреждаю**: список категорий/городов собран вручную и
  **не проверен на актуальность** — из этого окружения нет доступа к
  avito.ru, чтобы свериться с реальной структурой сайта (см. раздел про
  блокировку ниже). Слаги URL стабильны у Avito годами, но если
  какая-то категория переименовалась или ссылка ведёт не туда — это
  сразу видно по кнопке «Проверить на Avito» до того, как фильтр
  сохранится. Нужной категории нет в списке — используй второй способ.

- **🔗 Вставить ссылку с Avito** — старый надёжный способ: настрой поиск
  на сайте (город/цена/категория/что угодно) и просто вставь адрес из
  браузера. Работает для абсолютно любых фильтров Avito, не ограничен
  куцым списком категорий бота.

**Управление фильтром** — у каждой карточки в `📋 Мои фильтры` есть
кнопки: 🔄 проверить сейчас, ⏸/▶️ пауза/возобновить, ⏱ интервал
(пресеты 5/15/30/60 мин), 🗑 удалить (с подтверждением).

Часть тонких настроек пока доступна только командами (не вынесена в
кнопки):

| Команда | Что делает |
|---|---|
| `/renamefilter старое новое` | Переименовать, история и статистика сохраняются |
| `/seturl имя ссылка` | Заменить ссылку поиска без потери истории просмотренных id |
| `/setkeywords имя слово1,слово2` | Скрывать объявления с этими словами в заголовке (`-` — очистить список) |
| `/setprice имя мин макс` | Доп. ограничение цены поверх того, что уже фильтрует сам Avito (0 — без ограничения) |
| `/cancel` | Отменить текущий диалог |

Ключевое слово/цена, указанные в гиде по категориям, зашиваются прямо в
ссылку поиска (Avito фильтрует сам); `/setkeywords` и `/setprice` — это
отдельная, дополнительная фильтрация уже загруженных объявлений на
стороне бота (полезно, когда нужного сочетания нет в фильтрах сайта).

При добавлении фильтра первая проверка не присылает уведомлений о уже
существующих объявлениях — она только запоминает текущий список
(baseline). Дальше в чат прилетают только по-настоящему новые
объявления — с фото (если есть) и кнопкой «Открыть на Avito». Бот также
следит за ценой уже виденных объявлений и присылает отдельное
уведомление, если цена упала.

Если фильтр не может загрузиться много раз подряд (похоже на
устойчивую блокировку антиботом), бот сам ставит его на паузу — чтобы не
долбить сайт впустую — и пишет об этом в чат. Возобновляется кнопкой
▶️ на карточке фильтра или командой `/resume имя`.

Все команды (включая `/pause`, `/resume`, `/removefilter`, `/check`,
`/checkall`, `/status`, `/stats`, `/myfilters`, `/addfilter имя ссылка`
одной строкой) по-прежнему работают напрямую — кнопки не заменяют их, а
избавляют от необходимости их помнить. Список команд также
зарегистрирован в самом Telegram (кнопка «Меню» / автодополнение при
вводе `/`).

### Настройки через переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — (обязательна) | Токен бота от @BotFather |
| `AVITO_BOT_DB` | `avito_monitor/bot/avito_bot.db` | Путь к файлу SQLite |
| `AVITO_BOT_POLL_SECONDS` | `60` | Как часто планировщик проверяет, какие фильтры «созрели» |
| `AVITO_DEFAULT_INTERVAL_MIN` | `15` | Интервал проверки по умолчанию для новых фильтров |
| `AVITO_MIN_INTERVAL_MIN` | `5` | Минимально допустимый интервал через `/setinterval` |
| `AVITO_MAX_FILTERS_PER_CHAT` | `10` | Лимит фильтров на один чат |
| `AVITO_MAX_NOTIFY_PER_CHECK` | `15` | Максимум сообщений о новых объявлениях за одну проверку (чтобы не заспамить) |
| `AVITO_ALERT_AFTER_FAILURES` | `3` | После скольких неудачных попыток подряд слать алерт о блокировке |
| `AVITO_ALERT_COOLDOWN_SECONDS` | `21600` (6 ч) | Не чаще какого интервала повторять алерт о блокировке |
| `AVITO_AUTOPAUSE_AFTER_FAILURES` | `20` | После скольких неудачных попыток подряд фильтр автоматически ставится на паузу |
| `AVITO_ALLOWED_CHAT_IDS` | не задано | Через запятую chat_id, кому разрешено пользоваться ботом. Пусто = открыт всем, кто напишет `/start` (обычно ок для личного бота, но храните токен в секрете) |
| `AVITO_ADMIN_CHAT_ID` | не задано | chat_id, которому доступна `/broadcast текст` — разослать сообщение во все чаты с фильтрами |

## Альтернатива: cron-скрипт `monitor.py`

Если интерактивный бот не нужен, а достаточно одного набора фильтров и
одного чата — используйте `monitor.py`, запускаемый по расписанию.

1. Скопируйте `config.example.json` в `config.json`, впишите фильтры:

   ```json
   {
     "filters": [
       {"name": "iphone-moskva", "url": "https://www.avito.ru/moskva?q=iphone&pmin=10000&pmax=50000"}
     ]
   }
   ```

2. Локально: `TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... python monitor.py`,
   добавьте в cron/Планировщик заданий на нужный интервал.
3. Через GitHub Actions: добавьте секреты `TELEGRAM_BOT_TOKEN` и
   `TELEGRAM_CHAT_ID` в Settings → Secrets, workflow
   `.github/workflows/avito-monitor.yml` крутится каждые 15 минут по
   расписанию. Учтите: расписания GitHub Actions работают только с
   дефолтной ветки репозитория и отключаются автоматически после ~60
   дней без активности — в таком случае перезапустите вручную
   (`workflow_dispatch`) или сделайте любой коммит.

## Как это работает

- Первый запуск для каждого фильтра только запоминает текущие
  объявления (baseline) — уведомлений не будет, чтобы не засыпать вас
  всей историей сразу.
- На последующих проверках отправляются только объявления, которых не
  было в прошлый раз, плюс отдельные уведомления о снижении цены у уже
  виденных.
- Стоп-слова/диапазон цены применяются уже после загрузки страницы —
  отфильтрованные объявления всё равно помечаются как виденные, чтобы не
  проверяться повторно; если потом ослабить условия фильтра, старые
  отфильтрованные объявления уже не «всплывут» как новые.
- Парсинг сначала пробует структурированные данные (`ld+json` на
  странице), при неудаче — HTML-разметку по `data-marker`. Avito
  периодически меняет вёрстку — если объявления перестали парситься,
  скорее всего придётся поправить `parse_via_data_marker` в
  `avito_client.py`.

## Тесты

```bash
cd avito_monitor
pip install -r requirements-dev.txt
pytest
```

Покрыты: парсинг и клиентская фильтрация (`avito_client.py`), хранилище
и миграции схемы (`db.py`), команды бота, диалог добавления фильтра,
inline-кнопки, авто-пауза/резюме, уведомления о снижении цены,
экспорт/импорт (`bot.py`). Реальный Telegram API не дёргается — сеть
подменяется моками.
